# Third-party projects

DEC-K is designed as a selector that can be integrated into existing agent systems. The
repository does not redistribute model weights, benchmark videos, or the source trees of
the host systems.

- [M3-Agent](https://github.com/ByteDance-Seed/m3-agent) is released under Apache-2.0.
- [SiLVR](https://github.com/CeeZh/SILVR) is released under MIT.
- [Adaptive-k Retrieval](https://github.com/megagonlabs/adaptive-k-retrieval) is released under
  BSD-3-Clause and provides the Adaptive-k baseline implementation.
- [Adaptive-RAG](https://github.com/starsuzi/Adaptive-RAG) is released under Apache-2.0 and
  provides the query-complexity classifier baseline.

Follow each project license and dataset terms when running the complete benchmark pipelines.
